# Microsoft Certification Labs

Laborationsmaterial och PowerShell-skript för svenska läroböcker om Microsofts certifieringar.

Materialet är framtaget av Kristian Skog som ett praktiskt komplement till certifieringsböckerna.

## Tillgängliga laborationspaket

| Certifiering | Laborationsmaterial | Status |
|---|---|---|
| AZ-900 | PowerShell-laborationer 1-4 | Under förberedelse |
| AZ-104 | PowerShell-laborationer | Planerat |
| SC-900 | PowerShell-laborationer | Planerat |
| SC-500 | PowerShell-laborationer | Planerat |
| AI-901 | Praktiska laborationer | Planerat |
| AI-500 | Praktiska laborationer | Planerat |

## Hämta laborationsmaterial

Färdigställda laborationspaket publiceras som ZIP-arkiv under [Releases](../../releases).

Varje bok har ett eget lösenordsskyddat arkiv. Lösenordet finns i den tillhörande boken.

Arkiven innehåller laborationsguider, skript och instruktioner för att skapa, kontrollera och återställa testresurser.

## Förutsättningar och säkerhet

Vissa laborationer kräver en Azure-prenumeration, lämpliga behörigheter eller särskilda licenser. Azure-resurser kan medföra kostnader.

Läs laborationsguiden innan du kör ett skript. Använd endast resurser och miljöer som du har rätt att administrera.
